# FinTrack

Personal finance tracker with Firebase Realtime Database synchronization.

## Updated editing experience

- Professional modal editing across Bank, Cash, Income, Expenses, Loans, Savings, Savings Contributions, Business, Budgets, Mom's Money, and Sales.
- Consistent validation, responsive mobile layouts, loading states, and clear save/cancel actions.
- Professional confirmation dialogs replace browser delete alerts.
- Linked expense and savings balances remain synchronized with Bank/Cash records when edited.
- Expense itemized breakdowns can be edited directly inside the expense modal.
