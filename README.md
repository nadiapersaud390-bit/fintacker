# FinTrack — Personal Finance

FinTrack is a single-page personal finance dashboard backed by Firebase Realtime Database and Firebase Authentication.

## Included modules

- Dashboard
- Bank and Cash ledgers
- Income and Expenses
- Loans and Savings
- Business and Sales
- Mom's Money ledger
- Financial Calendar and custom reminders
- Monthly Reports with print / PDF support
- Activity History with deletion recovery

## New features in this build

### Financial Calendar
- Monthly calendar view for expenses, loan due dates, savings targets, income dates, and custom reminders.
- Upcoming schedule and overdue counters.
- Add, edit, complete, and delete custom reminders.
- Upcoming items also appear on the Dashboard.

### Monthly Reports
- Select any month.
- Review monthly income, paid expenses, net cash flow, opening and closing Bank/Cash balances, business results, sales profit, savings contributions, unpaid bills, loans, savings progress, and transaction details.
- Use **Print / Save PDF** to produce a printable monthly report.

### Activity History and Undo
- New additions, edits, deletions, and restorations are recorded with user, date, time, area, record, and changes.
- Deleted records can be restored from the Activity History page.
- A quick **Undo** button appears after deletions.
- Activity tracking begins when this version is first used; it cannot reconstruct changes made in older versions.

## Run

Open `index.html` in a modern web browser. Internet access is required for Firebase and Chart.js.
